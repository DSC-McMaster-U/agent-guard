Use December capacity to connect approvals and the simulated outbox once that walkthrough works. Sprint 6 starts January 5, 2027. The mid-year showcase is January 18–22, with the exact day TBD. Show the reason for each decision. Refresh the page and restart the backend. Capture the same three saved request IDs in the browser afterward. [Browser walkthrough #134](https://github.com/DSC-McMaster-U/agent-guard/issues/134)
- [ ] **Codex — Fix the first failure the walkthrough exposes.** Check empty history, database outage during refresh, and recovery when the database returns.
